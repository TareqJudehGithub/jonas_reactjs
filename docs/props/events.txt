Handling events in React
 - React is declarative, so handling events in React is just passing the function head
   to the action element, without the need to use addEventListener() like the case 
   in JS.

    function handleClickButton()
    {
      return // some action (show alert, show a popup, etc..)
    }
      <button onClick={handleClickButton}>
  
  - onClick here is a built-in React prop and not a JS attribute.
  - handleClickButton is a pointer to the function that should be 
    executed upon clicking onClick (when the event occurs).

 - In case the function to be executed was containing parameters, 
   we should wrap it inside the React built-in prop function:
    onClick={() => handleClickButton(argument)}
  - Doing so, we guarantee not execute the handle function, not unless 
    we trigger the executing prop function.
